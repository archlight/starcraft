🚀 Pocket Commanders

Gather. Build. Outsmart. A real-time strategy game you can learn in five minutes.

🖱 Left-click / drag: select units
🖱 Right-click: move, attack, gather
A then click: attack-move
B: build menu (with a Bitbot)
Ctrl+1…9: save a squad, 1…9: recall
Shift+click: queue up orders
F1: find an idle Bitbot
Space: jump to the action
Arrow keys / screen edge / minimap: move camera
Mouse wheel: zoom   F10: pause
