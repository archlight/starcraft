# Pocket Commanders

A beginner-friendly real-time strategy game for the browser. Gather, build, and outsmart an AI enemy.

## Play

Open `index.html` in any browser. No install or build step.

## Code

- `js/game.js`: simulation (units, buildings, pathfinding, combat, economy)
- `js/ai.js`: enemy commander
- `js/ui.js`: controls, rendering, HUD, coach
